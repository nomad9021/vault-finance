# Installers

Everything for getting Vault Finance running, split by what you're installing:

- [**`server/`**](server/) — interactive scripts that stand up the **server**
  (the Docker stack that holds your data) on Linux, macOS, or Windows.
- [**`desktop/`**](desktop/) — how to get or build the **desktop app** for
  Windows, macOS, and Linux (downloaded from GitHub Releases, or built from
  `apps/desktop`).

Most people install the server once on an always-on machine, then install the
desktop app on each device they use. Start with [`server/`](server/).
